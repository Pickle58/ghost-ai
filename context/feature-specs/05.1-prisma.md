## Contract

Edit `src/prisma/contract.prisma`. Remove `User` and `Post`. Do not keep the starter models.

Add:

```prisma
// use prisma-8

enum ProjectStatus {
  @@type("pg/text@1")
  DRAFT = "DRAFT"
  ARCHIVED = "ARCHIVED"
}

model Project {
  id             String        @id @default(uuid())
  ownerId        String
  name           String
  description    String?
  status         ProjectStatus @default(DRAFT)
  canvasJsonPath String?
  createdAt      TimestamptzString @default(now())
  updatedAt      temporal.updatedAtString()

  @@index([ownerId])
  @@index([createdAt])
}

model ProjectCollaborator {
  id        String @id @default(uuid())
  projectId String
  project   Project @relation(fields: [projectId], references: [id], onDelete: Cascade)
  email     String
  createdAt TimestamptzString @default(now())

  @@unique([projectId, email])
  @@index([email])
  @@index([projectId, createdAt])
}
```

Rules:

- Use Prisma 8 PSL. Do not add a `generator` or `datasource` block.
- `ownerId` stores the Clerk user ID as text.
- Use `String @id @default(uuid())` for both models. Do not use sequential integer IDs.
- Put `onDelete: Cascade` only on the owning `ProjectCollaborator.project` relation.
- Use `TimestamptzString` and `temporal.updatedAtString()` so Node 24 does not need global `Temporal`.
- Do not store a slug. Slugs stay derived in the UI.
- Do not add extra fields unless Prisma requires them.

Then run:

```bash
pnpm exec prisma contract emit
```

## Database

The database is empty of Ghost tables. Do not run `prisma contract infer` or `prisma db sign`.

Set `DATABASE_URL` in `.env` for PostgreSQL 15 or newer. `src/prisma/db.ts` loads `dotenv/config`, which reads `.env`, not `.env.local`.

- If `.env` already has a working `DATABASE_URL`, use it.
- If it is missing, run `npx create-db@latest`, write only the connection string to `.env`, and show the claim URL so the database can be kept. Do not print or commit the connection string. Clerk keys stay in `.env.local`.

Then apply the contract:

```bash

```
